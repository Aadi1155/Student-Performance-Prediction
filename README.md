Student Performance Prediction System is a Machine Learning project designed to predict a student's academic performance based on factors such as study time, attendance/absences, and previous grades.
The system uses the UCI Student Performance Dataset and applies data preprocessing, exploratory data analysis, and regression techniques to build a predictive model. Multiple Machine Learning models are trained and evaluated using RMSE (Root Mean Squared Error) and R² (R-squared) to understand their prediction performance.
A Streamlit-based web interface is also developed, allowing users to enter student information and receive a predicted academic performance result.
🎯 Key Features
- Data cleaning and preprocessing
- Handling categorical and numerical data
- Exploratory Data Analysis (EDA)
- Machine Learning regression
- Model evaluation using RMSE and R²
- Student performance prediction
- Interactive Streamlit web application
🛠️ Technologies
Python Pandas NumPy Matplotlib Scikit-learn Streamlit
